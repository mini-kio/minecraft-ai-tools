# MCT Fabric companion

Install exactly one `dist/mct-bridge-<game-version>.jar` into a matching Fabric client's `mods` folder. Requires Fabric Loader >=0.19.5. See [setup, protocol and build instructions](../../docs/fabric.md).

`compatibility.json` distinguishes compiled JARs and checked hook signatures from actual client runtime checks. Builds cover 1.20 through 26.3; untested runtime scenarios are explicitly marked.
